# Project C — Pinball

**A stylized 3D pinball combat prototype built in Unity.**

Launch the ball, chain ricochets, return shots with flippers, and dash into enemies while defending the base. The project explores toy-like characters, procedural animation, and real-time mesh deformation.

**Status:** In development · **Engine:** Unity · **Rendering:** Universal Render Pipeline
